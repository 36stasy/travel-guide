# Утренняя рассылка мест + растущий гайд по путешествиям

Каждое утро в 9:00 в Telegram приходят **два места планеты**: альбом из 3–7 фотографий
и структурированный разбор — почему это место, что именно смотреть, лайфхаки с форумов,
когда ехать, что здесь снимали, факты и как встроить в маршрут.

**Повтор невозможен.** Что отправлено — записано в `data/log.json` и больше никогда не берётся.
Порядок мест считается по кругу через десять регионов, поэтому два дня подряд не приходит
из одной части мира, а одна страна не повторяется рядом.

Работает на GitHub Actions — **ноутбук для этого не нужен**.

---

## Что где лежит

| Путь | Что это |
|---|---|
| `data/places.json` | каталог мест-кандидатов (198 мест, 88 стран) |
| `data/continents.json` | карта «страна → континент» для разделов сайта |
| `cards/<id>.json` | готовая карточка места: тексты, лайфхаки, фото |
| `data/log.json` | что и когда отправлено — гарантия от повторов |
| `data/config.json` | настройки: кому слать, сколько мест в день |
| `scripts/send_daily.py` | утренняя отправка в Telegram |
| `scripts/build_site.py` | пересборка сайта-гайда в `docs/` |
| `docs/` | сам гайд: открывается по ссылке с телефона |
| `setup/daily.yml` | расписание для GitHub Actions |

Фотографии **не хранятся** в репозитории — только ссылки. Поэтому всё вместе весит
несколько мегабайт. Telegram копирует снимки себе в чат навсегда.

---

## Разовая настройка

### 1. Завести бота
В Telegram открыть **@BotFather** → `/newbot` → придумать имя → он пришлёт токен
вида `8123456789:AAH...`. Это пароль от бота, никому не показывать.

Затем **написать своему боту любое сообщение** — иначе Telegram не разрешит ему писать первым.

### 2. Положить токен в Secrets
`Settings` → `Secrets and variables` → `Actions` → `New repository secret`
Имя: `TELEGRAM_BOT_TOKEN`, значение: токен от BotFather.

Секреты зашифрованы и не видны в коде, даже если репозиторий открытый.

### 3. Включить расписание
Создать файл `.github/workflows/daily.yml` и вставить в него содержимое `setup/daily.yml`.

### 4. Включить сайт
`Settings` → `Pages` → Source: `Deploy from a branch`, ветка `main`, папка `/docs`.
Через минуту гайд открывается по адресу `https://36stasy.github.io/travel-guide/`.

### Проверка
`Actions` → «Утренняя рассылка мест» → `Run workflow`. Карточки должны прийти в бот сразу.

## Разделы сайта: континент → страна → место

На главной под большими разборами стоит блок **«По континентам»**. Дальше всё вложено:

```
главная → Азия → Вьетнам → Шондоонг
```

Страница континента показывает список стран со счётчиком мест и сетку всех мест континента
с собственным поиском. Страница страны — все места этой страны. На каждой странице сверху и
снизу хлебные крошки, чтобы возвращаться на шаг назад, а не в начало.

Страны разложены по шести континентам в `data/continents.json`. Если добавляешь место в стране,
которой там ещё нет, она попадёт в раздел «Остальной мир», и сборка честно напишет об этом
в консоли — тогда просто допиши страну в нужный список.

**По умолчанию в разделах только те места, что уже пришли в рассылке** — чтобы утро оставалось
сюрпризом. Написанные, но не отправленные считаются отдельно: внизу страницы страны и континента
стоит строчка «ещё N мест написаны и ждут своей очереди». Если хочется видеть сразу все карточки,
в `data/config.json` поменять `"site_show_upcoming"` на `true`.

## Когда карточки закончатся

Рассылка сама предупредит в Telegram за четыре дня. Нужно включить ноутбук
и сказать Claude: **«допиши карточки для утренней рассылки»**.

## Полезные команды

```bash
python scripts/send_daily.py --dry-run   # показать, что уйдёт сегодня, никому не отправляя
python scripts/build_site.py             # пересобрать сайт вручную
```
